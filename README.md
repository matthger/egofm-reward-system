# egoFM Rewardsystem

A full-stack web application for egoFM, built with **Angular (Frontend)**, **NestJS (Backend)**, **PostgreSQL**, and **NGINX**. The entire system is containerized using Docker and includes hot reload support for development.

## Overview

### Home page
This is the home page of the app, where users can see the currently playing stream, access different genres, track their daily progress, and view the leaderboard.

![Home page screenshot](/docs/images/homescreen.png)


### Rewards page
The rewards page shows how users can earn points by completing tasks, like listening to egoFM, following on social media, or inviting friends. Points can be used to unlock badges and rewards.

![Rewards page screenshot](/docs/images/rewardsscreen.png)

### Account page
On the account page, users can view and edit their personal information, such as username, email address, and password. It also displays additional details like the user’s birthdate and the date they joined egoFM.

![Account page Screenshot](/docs/images/accountscreen.png)
